**Goal:** Teach first, show the app second. Soft CTA: App Store / link in bio.  
**Format:** Face-to-camera + cut to app screen recording.  
**Length:** ~25–40 seconds per TikTok.

## Quick recording checklist

- [ ] Film face takes first (same lighting/outfit for the week if you want consistency)
- [ ] Capture screen recordings with Large Text / clean demo data (fake but realistic numbers)
- [ ] Burn-in captions on TikTok (most watch muted)
- [ ] First 1 second = the hook line on screen as text
- [ ] Bio link → App Store
- [ ] Dual-post TikTok → Instagram Reels same day (optional, same file)
- [ ] On X: reply to your own post once with a screenshot or 15s clip if engagement is low
